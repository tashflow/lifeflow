- **Command:** `bun run test:unit -- --verbose` (`jest tests/unit/stage03e.regression.test.ts --verbose`)
- **Result:** **PASSED — 1/1 suite, 12/12 tests passing (0.505s)**

  11. `toFriendlyFirestoreErrorMessage` and `buildFirestoreErrorInfo` produce non-leaking diagnostics with preserved `.message`.
